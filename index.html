How FinPulse syncs across devices without accessing personal Drive files

Why Users Can Trust This Permission (`drive.appdata`)

FinPulse requests only the https://www.googleapis.com/auth/drive.appdata scope. Google restricts this scope to a hidden application folder (`appDataFolder`). FinPulse cannot view, list, download, or modify any other files or folders in the user's Google Drive.

Developer Tip: Once you create your free Client ID in Google Cloud Console, paste it above (or hardcode it into DEFAULT_GOOGLE_CLIENT_ID in the script) so all your Play Store / GitHub Pages users can sign in with 1 tap.

Quick 3-Minute Setup for GitHub Pages / Play Store:

  1. Go to Google Cloud Console, create a project, and enable the Google Drive API.
  2. Under OAuth consent screen, add the non-sensitive scope .../auth/drive.appdata.
  3. Under Credentials → Create Credentials → OAuth client ID, choose Web application.
  4. Add your GitHub Pages URL (e.g. https://yourusername.github.io) and http://localhost under Authorized JavaScript origins, then copy the Client ID here.
